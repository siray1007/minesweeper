# 扫雷（Rust 版）

Rust + egui 重写的扫雷，**5.5MB 单文件**、双击秒开、毫秒级无猜求解器、粒子动画。

## 运行

双击 `扫雷.exe` 即可，无需任何环境。

## 功能

- **无猜模式**：约束传播求解器，纯逻辑可解
- **账号系统**：注册/登录，战绩绑定账号
- **排行榜**：按难度排名（本地 JSON 存储）
- **三难度**：训练 9×9 / 进阶 27×27 / 极限 81×81
- **动画**：reveal 涟漪、爆炸粒子
- **中文界面 + 深色主题**

## 操作

| 操作 | 说明 |
|---|---|
| 左键 | 翻开 |
| 右键 | 标记 / 取消标记 |
| 中键 / 双击数字 | 快速展开 |

## 数据位置

账号与战绩保存在：

```
%LOCALAPPDATA%\MinesweeperRust\store.json
```

## 从源码构建

需要安装 [Rust](https://rustup.rs) 工具链（MSVC），然后：

```bash
cargo build --release
```

产物在 `target/release/minesweeper-rs.exe`。

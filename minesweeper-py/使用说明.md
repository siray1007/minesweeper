# 扫雷（Python 版）

深色硬朗、赛博朋克风格的扫雷游戏，支持**无猜模式**——每一局都能靠纯逻辑推断解开，不再有 50/50 的必猜死局。

## 运行

双击 `扫雷.exe` 即可，无需安装 Python 环境。

## 操作

| 操作 | 说明 |
|---|---|
| 左键 | 翻开格子 |
| 右键 | 标记 / 取消标记雷 |
| 中键 / 双击数字 | 周围旗数匹配时快速展开 |
| `R` | 重开当前对局 |
| `Esc` | 返回大厅 |

## 难度

| 模式 | 棋盘 | 雷数 |
|---|---|---|
| 训练 | 9×9 | 10 |
| 进阶 | 27×27 | 100 |
| 极限 | 81×81 | 800 |

## 功能

- **无猜模式**：布雷时自动验证可解性，保证纯逻辑可解
- **账号系统**：本地注册/登录，战绩绑定账号
- **排行榜**：本地战绩优先，后台合并在线榜单
- **玩家档案**：胜率、最佳成绩、最近战局
- **14 种语言**：简体/繁体/文言文/英文等，左上角切换
- **深色/浅色主题**：登录页或大厅右上角切换
- **音效**：翻开/标记/爆炸/胜利提示音，可开关

## 数据位置

账号与战绩保存在：

```
%LOCALAPPDATA%\CyberMinesweeper\
```

删除该目录会清除本地账号和战绩（在线榜单不受影响）。

## 在线排行榜

读取公开的 `rankings.json`，未配置令牌时为只读。写回需设置环境变量 `MINESWEEPER_GITHUB_TOKEN`。

# 赛博扫雷使用说明

## 基本操作
- 左键：翻开格子
- 右键：标记或取消标记
- 双击数字：当周围标记数匹配时，快速展开周围格子
- Escape：从对局或排行榜返回大厅

## 模式
| 模式 | 棋盘 | 雷数 |
| --- | --- | --- |
| 训练 | 9x9 | 10 |
| 进阶 | 27x27 | 100 |
| 极限 | 81x81 | 800 |

## 账号
1. 首次使用需要创建账号
2. 用户名至少 2 个字符
3. 密码至少 4 个字符
4. 战绩会绑定到当前账号
5. 旧版数据库会在首次启动时自动迁移，`ssr` 等原账号继续有效
6. 正式数据目录为 `%LOCALAPPDATA%\CyberMinesweeper`

## 战绩榜
- 通关后会保存本地战绩
- 排行榜会优先显示本地数据
- 云端同步失败不会影响离线游玩

## 大棋盘
极限模式支持滚动和缩放。按住 Ctrl 滚动鼠标滚轮可以调整缩放。
